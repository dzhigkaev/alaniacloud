# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this project or the site at
[www.alaniacloud.com](https://www.alaniacloud.com) — for example an exposed
storage path, a leaked credential in a commit, or a misconfiguration — please
report it **privately**.

- **Email:** timur.djigkaev@gmail.com
- Or open a private report via GitHub's
  [Report a vulnerability](https://github.com/dzhigkaev/alaniacloud/security/advisories/new)
  button.

Please **do not** open a public issue for security problems.

### What to expect

- I aim to acknowledge your report within **5 business days**.
- Please allow up to **90 days** for a fix before any public disclosure.
- Good-faith research is welcome; I won't pursue action against reporters who
  follow this policy and avoid privacy violations or service disruption.

Thank you for helping keep this project safe.
